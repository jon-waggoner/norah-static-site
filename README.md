# Code for Norahs site

This is a game called **Star Catcher**! Colorful stars fall from the sky and you move your mouse to catch them in a basket. Every star you catch gives you 1 point. Sometimes a picture of a puppy falls down instead — catch the puppy and you get 3 points! You have 5 hearts, and every time you miss a star you lose one. The game gets faster the more stars you catch. Try to get the highest score you can!
